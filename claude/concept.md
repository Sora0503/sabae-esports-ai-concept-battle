# Claude Concept: 4人目は、あなた。

## タイトル
**4人目は、あなた。**
（英題：Player 4 is You）

## ひとことで
**見た人が、そのまま「4人目のプレイヤー」になるメインビジュアル。**
画面のこちら側から見た構図で、手前に「あなたの手」と、鯖江の技でできたコントローラーがある。
その向こうで、おじいちゃん、女の子、車いすの男の子、レッサーパンダが「一緒にやろう！」と手を振っている。

## コンセプト
イベントの合言葉は「ゲームがあれば、つながれる。」。
この絵では、つながる相手を絵の中だけで完結させない。**絵を見ているあなた自身を、仲間に入れる。**

- ゲームから見れば、年齢も車いすも関係ない。見えるのは、同じゲームを楽しむ「プレイヤー」だけ。
- 一人称の視点（POV）にして、見た人の手がコントローラーを握っている。だから見た人は「見る人」ではなく「誘われている人」になる。
- イベントに初めて来る人、ゲームをやったことがない人へのメッセージ：**あなたの席は、もう空いている。**

## 鯖江らしさ（新しい世界観＝伝統とデジタルが同じ線でつながる）
| 鯖江の象徴 | 絵の中で |
|---|---|
| **めがね**（フレームの国内シェア約95%） | あなたのコントローラーが、**めがねの形**。金の丸いレンズ2つをブリッジと鼻パッドがつなぐ。登場人物も全員めがね |
| **越前漆器**（河和田の漆と蒔絵） | コントローラーは**黒い漆塗り＋金の蒔絵**。背景の大きな丸は**朱の漆**で、中に金の蒔絵 |
| **西山公園のつつじ** | 朱の丸の中の金の蒔絵の花 |
| **レッサーパンダ**（西山動物園） | おじいちゃんの肩で、両手を上げて応援している |
| **デジタル・eスポーツ** | 朱の丸から外へ広がる金の線は、**蒔絵の金線が電子回路に変わっていく**もの。伝統の線と回路の線は、どちらも「つなぐ線」 |
| **多世代・障がいの有無を問わない** | おじいちゃん、中高生の女の子、車いすの男の子が並ぶ。誰かが誰かを「助ける」絵ではなく、全員が同じ側にいる |

## 色
**黒・朱・金**の3色に絞った、越前漆器の配色。
人物の肌と服だけに色を残して、遠くからでも「人が笑っている」ことが分かるようにした。
赤い丸は遠目にも目立ち、ポスターやSNSのサムネイルでも埋もれない。

## 構図
- 縦 4:5。上半分は朱の丸と金の放射線、中央に3人とレッサーパンダ、下にあなたの手とコントローラー。
- 視線は全員がこちら（見た人）を向いている。男の子とレッサーパンダは手を振っている＝**招待**。
- 文字は入れていない。上の放射線の部分は、イベント名を重ねても絵が負けない余白になる。

## 他のAIとの違い（自己評価）
- ChatGPT 案「となりのライバル、同じ未来。」：おじいさんと車いすの女の子が並んで対戦し、大きなめがねのアーチが未来の鯖江を包む。塗りの完成度と、場面の温かさは3案でいちばん高い。ただ、見る人は「外から眺める人」のまま。鯖江の要素は、めがね（建築）に絞っている。
- Grok 案「同じまなざし」：職人とプレイヤーの集中した目がレンズで重なる、静かで強い絵。ただし多世代・誰でも参加できる、はレンズの向こうの人々に任されている。
- **Claude 案：見た人を絵の中に入れる。** 「誰でも参加できる」を、説明ではなく**あなたの手に持たせた**。めがね・漆・レッサーパンダも、**コントローラーという1つの物**と、その向こうで手を振る仲間に集めた。

## 審査員に届けたいこと
- 市長・SDGs推進センター：多世代、車いす、地域の伝統産業（めがね・漆器）が、1枚の中で同じ側に並んでいる。
- eスポーツの方：主役はコントローラーと「プレイヤー」。
- ミュージシャンの方：赤と金の放射は、ライブのステージの光のように「始まる瞬間」の高揚感。

## 気になる点（正直に）
- 女の子と男の子はコントローラーを持っていない（手を振る・肩を組む）。「誘っている」場面として残した。
- 手前のコントローラーはボタンを省いた形。めがねに見えることを優先した。
