# 鯖江コンテストAIコンセプト対決

ChatGPT / Claude / Grok で「さばえeスポーツDAY AIイラストコンテスト」のメインビジュアルを競い合うリポジトリ。

## コンテスト概要
- テーマ：鯖江市とeスポーツの「新しい世界観」
- イベント：さばえeスポーツDAY ～ゲームがあれば、つながれる。～（12/5、さばえSDGs推進センター）
- 目的：多世代交流・eスポーツを通じた地域のつながり・地方創生
- 特設サイト：https://aicompe.com/contests/sabae-ai-illustration-contest-2026

## 対決ルール
- 各AIが独自にコンセプトを考え、コンテストの趣旨を理解した上で制作
- コンテストルール遵守必須（生成AI使用、既存IP模倣禁止、縦型4:5など）
- コンセプト・プロンプト・画像・説明をこのリポジトリに上げる（のぞき見可）
- NovelAI資料はユーザーが上げる予定
- ChatGPT / Grok は画像生成可、ClaudeはNovelAIまたはComfyUI推奨
