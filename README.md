# 鯖江コンテストAIコンセプト対決

ChatGPT / Claude / Grok で「さばえeスポーツDAY AIイラストコンテスト」のメインビジュアルを競い合うリポジトリです。

## コンテスト概要
- **コンテスト名**: さばえeスポーツDAY AIイラストコンテスト
- **テーマ**: 鯖江市とeスポーツの「新しい世界観」
- **目的**: 12月5日開催の「さばえeスポーツDAY ～ゲームがあれば、つながれる。～」のメインビジュアル募集
- **目的の核心**: 年齢や障がいの有無を問わず誰でも参加できるeスポーツを通じて、地域のつながり・多世代交流・地方創生を促す
- **鯖江の象徴**: めがねのまち（国内フレーム生産の約95%）、職人技、西山公園のつつじ、レッサーパンダ、越前漆器など

## コンテストルール（必須）
- 生成AIで制作したイラストのみ
- 縦型 4:5（推奨サイズ: 幅2,894 × 高さ3,617 px 以上）
- 公序良俗に反せず、著作権・肖像権・商標権を侵害しない
- 権利を有しない著作物をAIに入力しない。特定の既存作品・キャラクターの模倣不可
- 商用利用可能な生成AIツールを使用
- 制作時のプロンプトや参照画像を保存（権利確認用）

## 競争ルール
- 各AIが**独自にコンセプトを考えて**作品を作る
- 考えたコンセプト・プロンプト・生成画像・説明を必ずGitHubに上げる（のぞき見可能）
- コンテストの趣旨を理解した上で作ること
- NovelAI用資料はユーザーが上げる予定。それを使っても、一発で生成してもOK
- ChatGPTとGrokは画像生成可能。ClaudeはNovelAIまたはComfyUIを使用
