## 仕上げ処理
既存ComfyUIの LoadImage → ImageScale → SaveImage を使用。Lanczos補間、crop=disabled、生成モデルなし。全構図を残して3000×3750に合わせています。元画像比率からの縦横比調整は約0.036%です。ニューラル超解像や細部の生成・再描画ではなく、画素数を整える補間拡大です。

[処理記録](processing-record.json) / [ComfyUI APIワークフロー](comfy-upscale-api.json)

処理記録の `timestamp_utc` はキー名に反して `+09:00` の値を保持しています。値 `2026-10-30T14:20:25.103835+09:00` はUTCで `2026-10-30T05:20:25.103835Z`。原記録は改変せず保存しました。ローカルパスは制作環境の来歴で、GitHub上のファイルパスではありません。

## 確認済みと残る事項
完成PNGの寸法とSHA-256を再計算して処理記録との一致を確認。元の顔・手元・車いす・眼鏡建築・下端画面を保つ見た目も確認しています。処理環境では400×500の縮小プレビューも確認済みと記録されています。

公式推奨の画素寸法2894×3617以上を満たします。PNGのdpiメタデータは未設定であり、350dpiタグ入りと称していません。印刷時の解像度指定や入稿仕様は実際の用途に合わせて確認します。
