# E32 フォーカス・インペイントを Claude だけで（2026-10-31・Claude）

## 仮説
人が塗らなくても、自動操作の塗り＋フォーカスエリアでインペイントが効く。前回（E11、R6-1、R6-2）の「塗りが入らない」は別の原因。

## 手順
1. 新しいタブで novelai.net/image を開く。
2. 元画像 `画像\R3-2_2人手渡し_横長_位置AI_s1340243550.png`（1216×768）を i2i の file input に入れる。
   - 「この画像で何がしたいのですか？」が出る。先に「メタデータをインポート」（プロンプト・キャラ・設定）、もう一度入れて「画像2画像」。
   - ※ 1回目、別の file input に入れたら「NovelAIポーション」に入った（2 アンラスになる）。削除した。
3. 左の i2i 欄の「インペイント」→ 編集画面。
4. 「マスク追加」を押す → ペンサイズ 12 にする → 手の上をドラッグで塗る（7本）。紫の塗りが画面に出るのを確認。
   - ペンサイズ 38 は大きすぎて顔まで塗れた。元に戻すで消せる。
5. 下の4つ目の道具「フォーカスエリア選択」→ 手のまわりを四角でドラッグ。
6. 「保存して閉じる」→ 左の表示が「ベースプロンプト」に変わる（インペイントの状態）。
7. 「1枚のみ生成」（0 アンラス、seed はランダム）。同じマスクのまま2回。

変わった範囲は塗った手のまわりだけ（差分画像 `E32-1_差分.png`）。

絵：男性の手は2枚とも、パンを上からつかむ形になり、指は5本に読める。女性の手は薄く細くなり、腕と溶けた（パンを渡す手が消えた）。

## 判定
- **自動操作の塗りは保存される。** 前回失敗したのは塗りではなく、seed が同じだった／マスクの層を選ばずに塗った、のどちらか。手順書の「人が塗る」は誤り。
- フォーカスの外の変化 0%：合格。
- 指：男性は合格、女性は不合格（手が消える）。→ 塗る範囲とプロンプトの問題。
