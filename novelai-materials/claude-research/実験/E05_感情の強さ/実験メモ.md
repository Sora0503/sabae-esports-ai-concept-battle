# E05 感情の強さ（2026-10-29・Grok）

## 仮説
感情ツールの強さ −2／0／＋2 で、表情だけが段階的に強くなる。追加プロンプトは、選んだ感情に上乗せされる。体と服は変わらない。

## 変える条件（1つだけ）
1. 怒りだけ。強さは画面の 0／2／5。追加プロンプトは空。
2. 怒り、強さ 0。追加プロンプトのあり／なし（`tears`）。
3. 強さ 0、追加プロンプト空のまま、感情だけを替える（怖い、ワクワク、飽きる、イライラ、まさか、傷つく）。
4. 怒り、強さ 0。元画像だけを替える（M7c、W6、2人）。

## 固定する条件
ディレクターツールの「感情」。元は `画像\M_感情差分\M00_元_無表情.png`。変換ボタンは毎回 0 だった。背景の削除は押していない。拡大の 1 アンラスも押していない。

画面の強さは defry の 0〜5。ボタンは `Math.max(0, defry-1)` と `Math.min(5, defry+1)`。計画の −2 は画面に無い。defry 0 の横の文字は「弱い」。

追加の元画像は、この研究で出したものだけ。男性は `画像\S_タイプ別\M7c_ワイルド_colored_s1473889684.png`。高齢は `画像\S_タイプ別\W6_高齢女性_s1473889684.png`。2人は `実験\E03_動作タグ\130035_gen_s3980513291_8890d3.png`。

## 対照
強さの対照は、同じ M00 から出した怒りの defry 0（813×1288）。M00 本体は 768×1216 なので、拡大の誤差を混ぜない。感情を替えたときの対照も、この怒りの defry 0。

M7c・W6・2人は、元画像を出力サイズへ LANCZOS で合わせてから diff した。閾値は 20。

顔の範囲（M00 系、813×1288）は x160–660、y40–560。服の範囲は x80–740、y760–1220。
M7c と W6 の顔は x180–640、y40–520。服は x80–740、y700–1240。
2人の顔帯は x80–1200、y20–420。体は x80–1200、y430–780。

## 手順
1. M00 をディレクターツールの感情に入れる。
2. 怒りを、defry 0、2、5 で変換する。毎回、変換ボタンが `変換 0 アンラス` であることを読んでから押す。
3. 強さ 0 の怒りに、追加プロンプト `tears` を足して1枚。
4. 追加欄を空に戻し、強さ 0 で残りの6感情。
5. 同じ怒り・強さ 0 を、M7c、W6、2人の絵にかける。2人は 1216×768 で、変換は 0 だったので出した。
6. 顔と服を見て、diff の数字を残す。

## 判定（合格の基準に対して）

不合格。

強さの段階は、0 の軽いしかめ面、2 の額のマーク、5 の目の下の線、と絵は変わる。5 は 2 を強くしたものにはなっていない。0、2、5 は一直線の強さではない。

服の編み目・革ジャン・ストールは見た目では残る。画素は服の範囲でも 3〜6% 動く。強さ 2 対 0 では、顔 3.53% と服 3.36% が近い。合格の「顔以外が変わらない」には達しない。

追加の `tears` は涙として乗る。傷つくはマスクという新しい物が付く。2人は両方の顔が変わり、怒りマークと湯気が付く。

## 分かったこと → 手順書のどこに反映したか

手順書 §3 の感情の強さの行を更新した。状態は ❓ のまま。
