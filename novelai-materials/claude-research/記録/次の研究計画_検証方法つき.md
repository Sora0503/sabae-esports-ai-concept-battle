# 次の研究計画（仮説・検証方法・合格の基準）2026-10-29

NovelAI 側で「内部エラー」が続いたため、生成を止めた（残高 6064）。再開したら、下の順で進める。担当は Claude か Grok。
前提：手順書 `D:\AI\style_recipes\AI漫画の手順書\AI漫画_制作手順_NovelAI版.md`、ツール `D:\AI\NovelAI研究\tools\naitools.py`。

## 共通の進め方（毎回これに従う）
1. 実験フォルダを作る：`D:\AI\NovelAI研究\実験\<ID>_<名前>\`。最初に `実験メモ.md` をテンプレート（下）からコピー。
2. **1つの実験では、条件を1つだけ変える**。対照（変えない版）も必ず作る。seed は固定（同じ設定は生成されないので、比べる2枚は条件が違う）。
3. 生成ボタンの消費を読んでから押す。25 超えは押さない。
4. 生成後：`naitools.py collect <実験フォルダ> 30` → `catalog` → `sheet` で一覧 → 拡大して判定。
5. インペイントや合成は `diff` で「変わった範囲」を数字で残す。
6. 結果を `実験メモ.md` に書き、分かったことを手順書の該当工程に反映（✅ に変える）。

## 再開前の確認（エラーが直ったか）
- 普通の生成（参照なし、768×1216）を1枚。成功したら再開。失敗したら、時間をおく（短時間に大量に生成すると内部エラーが続くことがある：ユーザー談）。
- i2i（アップロードした画像）だけ失敗するなら、画像の大きさが生成サイズと同じか確認する（非公式の SDK 文書：サイズが違うとサーバーが 500 エラーを返す）。

## E01 フォーカス・インペイントで顔・手の品質を上げる（優先度：高）
- 仮説：四角で囲んで描き直すと、その範囲が約100万画素に拡大されて描かれるので、小さい顔や指が整う（公式）。Opus なら 0 アンラス。
- 方法：2人の横長の絵（R3-2 か A12）で、女性の手のまわりを「フォーカスエリア選択」で囲み、中を塗って生成。対照＝同じ塗りで、フォーカスなし。
- 判定：`diff` で変わった範囲が四角の中だけか。拡大して、指が5本か・線の細かさ。
- 合格：フォーカスありの方が、指が数えられ、線が細かい。囲みの外は 0.5% 未満しか変わらない。

## E02 合成の境目をなじませる（優先度：高）
- 仮説A：i2i 強度 0.2〜0.35 で全体を描き直すと、光と線がなじむ。顔は 0.35 を超えると変わり始める。
- 仮説B：「画像をインペイントする」で境目の帯（`compose` が出す `_mask.png` の形）だけを塗ると、顔を守ったままなじむ。
- 方法：`naitools.py compose` で作った合成（`画像\B_背景なじませ\B3_…png`）を i2i に入れる。A は強度 0.2／0.3／0.4。B は帯を手で塗り、インペイント強度 0.5 と 1。
- 判定：`diff` で顔の範囲の変化量。目で、境目の白い線・色の差が消えたか。
- 合格：顔の範囲の変化が小さく（目・口の形が同じ）、境目が見分けられない。
- 注意：前回、この i2i が2回とも内部エラー。まず E00 の確認をする。

## E03 2人の動作タグ（source# / target# / mutual#）（優先度：高）
- 仮説：公式の動作タグで、誰が誰に何をするかが守られ、手の絡みも整理される。
- 方法：横長、キャラクタープロンプト2つ。動作3種（hug、handing over bread → `source#giving` / `target#receiving` など、holding hands → `mutual#holding hands`）。対照＝タグなしで同じ文を自然文で書く。
- 判定：する側・される側が入れ替わらないか。人数。指の塊。
- 合格：3種のうち2種以上で、役割が正しく、手が読める。

## E04 三面図（ターンアラウンド）を基準にする（優先度：中）
- 仮説：`multiple views, turnaround, reference sheet, no text` で作った三面図を精密参照に入れると、横顔・後ろ姿でも同じ人になる（公式のコツ）。
- 方法：T01 の人物の言葉で三面図を作る（0）→ それを参照に、横顔・後ろ姿・俯瞰を生成（各5）。対照＝T01（正面の1枚）を参照にした同じ3枚（`研究_画角と精密参照.md` にあるもの）。
- 判定：髪の青い筋、ピアス、服の形が、後ろ・横で残るか。
- 合格：三面図の参照の方が、3枚中2枚以上で印が多く残る。

## E05 感情ツールの強さと追加プロンプト（優先度：中）
- 方法：M00（無表情）で「怒り」を、強さ −2／0／＋2（画面の −／＋）で。追加プロンプトに `tears` などを足した版。残りの感情（怖い、ワクワク、飽きる、イライラ、まさか、傷つく）も。
- 判定：顔以外が変わらないか（`diff` で体の範囲）。表情の強さの段階。
- 追加：男性（M7）、高齢（W6）、2人の絵でも試す（公式：1人・正面・ニュートラルが最適）。

## E06 リファレンス・インペイント（優先度：中）
- 仮説：白いキャンバスの隅に人物（基準）を置き、残りの白を塗ってインペイント、ベースに `reference inset` を入れると、その人物が描かれる（公式の上級テクニック）。精密参照を使わずに 0 アンラスで同一人物を出せるかもしれない。
- 方法：外部で 1216×768 の白キャンバスを作り、左端に T01 を縮小して黒い枠つきで置く（naitools.py で作れる）。i2i →「画像をインペイントする」で白の部分を塗る。
- 判定：T01 と同じ顔か。隅の参照が絵に残る（あとで切る）。

## E07 デクラッターで偽の文字・吹き出しを消す（優先度：中）
- 方法：偽の文字が出た画像（W3 のパーカー、G2 の看板、I2 の吹き出し）をディレクターツール→デクラッター。
- 判定：文字が消え、ほかが変わらないか（`diff`）。

## E08 カラー化の Defry（色補正 0〜5）と、線画→カラー化（優先度：低）
- 仮説：線画にしてからカラー化すると、画風を揃えたまま色を変えられる。Defry で色の濃さを抑えられる。
- 方法：M00 → 線画 → カラー化（`brown hair, cream sweater`）、Defry 0／3／5。
- 判定：元の画風・編み目がどこまで残るか。

## E09 画風を精密参照で固定する（優先度：中）
- 仮説：画風カタログで決めた1枚（例：K08 エッセイ漫画）を「絵柄」の参照に入れると、別の人物・場面でも同じ画風になる。
- 方法：K08 を参照（種類「絵柄」、強度1）、人物を M2f（平凡な男性）や W6（高齢女性）の言葉に。対照＝参照なしで画風の言葉だけ。
- 注意：Grok の記録では、種類のメニューを開くと画面が落ちた。落ちたら「キャラクター＆絵柄」のまま試す。
- 判定：点の目・線の太さが揃うか。

## E10 1ページを通しで作る（総合テスト）（優先度：最後）
- 4コマ（`page 4koma`）を、手順書どおりに作る：基準 → 感情差分 → 背景 → 合成 → 修正 → コマ割り → 吹き出し。
- かかった時間、アンラス、やり直しの回数を記録する。手順書の抜けを見つける。
