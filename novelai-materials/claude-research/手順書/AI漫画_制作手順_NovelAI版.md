## エージェントに渡す短い指示（コピペ用）
```
NovelAI で漫画を作る。次を守ること。
1. ポン出し禁止。キャラ基準 → 表情差分 → 背景 → 各コマの人物 → 合成 → 修正 → コマ割り → 文字、の順に、工程ごとに止まって人間に見せる。
2. キャラは「基準の1枚」を作り、以後のコマは精密参照（キャラクター＆絵柄、強度1・忠実度1）で作る。1枚 5 アンラス。
3. 表情だけ変えるときは、ディレクターツールの「感情」を使う（0 アンラス、体と服が変わらない）。
4. 2人以上は横長（1216×768）で、キャラクタープロンプトの欄を人物ごとに分ける。
5. 背景は `no humans, scenery, …` で別に作る。文字・吹き出しは AI に描かせない（品質タグ「標準」は吹き出しを消す）。
6. 手の修正は、画像の上の「画像をインペイントする」から、直す所だけをなぞって塗り、seed を変えて生成する。
7. 押す前に生成ボタンの消費アンラスを読む。25 を超えたら止まる。残高 4000 未満で止まる。
8. 生成したら拡大して確認（指、人数、髪と目の色、服、偽の文字）。PNG の設定を記録する（naitools.py meta / catalog）。
9. 作家名・作品名・既存キャラ名をプロンプトに入れない。他人の画像を参照に入れない。
```

## 3. 表情差分（コマで使う表情を先に作る）
- **ディレクターツールの「感情」**：基準を無表情（`neutral expression, closed mouth`）で作り、「ディレクターツールに送信」→「感情」→ 感情を選ぶ →「変換」。**同じ顔・服・ポーズのまま表情だけ変わる**。驚きのマーク・？・ハートも足される。0 アンラス。✅（`研究_感情ツールで表情差分.md`）
- 漫画の記号（汗、白目、湯気、怒りマーク、稲妻、キラキラ、ギャグ泣き）は、生成のときに言葉で出る。✅（`研究_漫画表現.md`）
- ❓ 感情の強さ（Emotion Level）と、追加プロンプト欄の効き。2026-10-29 の E05。画面の強さは defry の 0〜5 で、計画の −2 は無い。0 の横は「弱い」。M00 の怒りは、0 が軽いしかめ面、2 が額の怒りマーク、5 はマークが消えて目の下の短い線。5 は 2 を強くした顔ではない。同じサイズの diff（閾値20）は、2対0 が顔 3.53%・服 3.36%、5対0 が顔 4.03%・服 3.61%。服の編み目は見た目では残る。追加の `tears` は両目の涙を足す。Comment は angry・defry 0 のままで、追加文は残らない。強さ 0・追加空で、怖い（見開き・涙・汗）、ワクワク（笑顔と瞳の光）、飽きる（半目）、イライラ（歯を見せて睨む）、まさか（保存名 embarrassed。赤面と汗）、傷つく（涙と白いマスク。マスクは新しい物）。M7c は顔 13.52%・服 4.56%、W6 は顔 12.85%・服 5.64%。2人は両方の顔が怒りになり、男性の頬にマーク、頭の横に湯気。手はつながったまま。出力は 768×1216 が 813×1288、1216×768 が 1288×813。13回とも 0 アンラス。6049→6049。販売の規約は未確認。
